AppFolder 支持

把常用 App 动作、网站和联系人整理进桌面文件夹。需要 iPhone 与 iOS 27 或更高版本。

添加主屏小组件

  1. 长按主屏空白处 →「编辑」→「添加小组件」。
  2. 搜索 AppFolder，选择「直接启动」，再选择尺寸并添加。
  3. 长按已添加的小组件 →「编辑小组件」，在「动作」中选择 App、快捷指令或系统动作。
  4. 如需嵌套文件夹或混排网站与联系人，先在 App 的「我的分组」中新建并保存分组，再在系统面板的「分组布局」中选中它。
  5. 分组中的 App 动作需要与系统面板内的动作名称唯一匹配；网站不需要额外动作。保存后的「小组件配置检查」可提示缺失或同名冲突。

小组件放置和实际动作选择由你在系统界面完成。App 内的预览可以浏览文件夹，不会运行动作。

布局与外观

支持小号、中号、大号及超大竖屏主屏小组件；实际可选尺寸以设备系统为准。返回和翻页按钮显示在网格中，会占用格子。App 中可保存分组和子文件夹外观，包括图标大小、名称显示、底板、间距、边距、名称颜色与描边，也可保存命名外观预设。

在「编辑小组件」中开启「使用分组外观」，才会采用分组保存的外观；此选项默认关闭。未自定义的子文件夹继承上级外观。照片、符号、文字和日期样式可用于自定义图标，普通与深色版本分别保存。

锁屏入口

在系统锁屏编辑界面添加 AppFolder 的圆形或矩形启动组件，再选择已保存分组中的项目并配置对应动作。是否需要解锁由 iOS 控制。

网站与联系人

网站默认交给系统打开，也可选择 App 内 Safari、Chrome、Firefox 或「跟随 App 设置」。本机统一偏好只影响明确选择跟随的网站。输入、预览和导入不会访问网站；「获取网站信息」会在你点击后访问网站及其图标服务器，结果需选择采用。无法使用所选浏览器时，App 会提示并提供手动选择系统默认方式的入口。

联系人可手动输入，或通过系统选择器提供姓名与一个电话号码。点击联系人图块会通过 AppFolder 交给系统处理；电话依系统确认，短信不会自动发送，FaceTime 需要再次点按开始。编辑、保存和导入不会发起联系。

从 Safari 添加网站

在 Safari 分享面板选择 AppFolder，按需填写名称并点「保存」，然后自行打开 AppFolder →「我的分组」→「待添加网页」。选择网页和目标分组，再保存分组。取消或保存失败会保留待添加记录；只有成功保存后才移出列表。

备份与恢复

可导出整个资料库，或从分组菜单分享单个已保存分组。导入先预览，确认后新增分组副本并保留已有图标设置。当前格式为 v16，兼容读取 v1–16；系统动作需要在目标设备重新配置。完整备份还包含保存的动作资料库记录和外观预设，单组分享只携带相关记录。

文件可能包含联系人姓名、电话号码、完整网址和照片小图，请选择合适的保存位置或接收方。App 内删除内容不会删除已导出的副本。

常见问题

为什么点按没有打开预期 App？

先检查系统「编辑小组件」里的动作是否已选择，并在 App 的「小组件配置检查」中核对名称。动作缺失或重名时需要重新配置。若目标 App 已删除，请更换动作。

图标缺失、认错或修改后没有立即更新？

图标搜索需要联网。可在「修正图标」指定正确的 App Store 图标，或设置自己的图标。系统会缓存小组件画面，刷新可能有延迟；检查报告只表示最近一次匹配结果，不是当前桌面组件清单。

日期图标为什么没有在零点立即变化？

日期按设备的日历、时区和语言生成；小组件刷新时间由 iOS 安排，日期或设置变化后可能有延迟。此功能不读取日历事件。

AppFolder 会向开发者上传个人数据吗？

不会。没有账号、广告或统计 SDK。图标搜索会请求 Apple 服务；主动获取网站信息、打开网站或浏览时会请求相应网站及浏览器服务。所选联系人、图片、分组和预设保存在设备上。具体数据、联网和删除方式见当前隐私政策。

English support

Requires iPhone with iOS 27 or later. Hold the Home Screen → Edit → Add Widget → search AppFolder → Quick Launch. Select apps or shortcuts under Actions in Edit Widget. Save a layout in My Groups and select it under Group Layout. Action names must uniquely match; websites need no system action.

Enable Use Group Appearance to apply saved styling. Navigation icons use grid cells. Home Screen and Lock Screen sizes depend on iOS. Widget refresh and authentication are controlled by the system.

Contacts use AppFolder to hand off to the system; calls require confirmation, SMS is not sent automatically and FaceTime needs a separate Start tap. Only explicitly selected contacts and images are read. Website fetching and browsing contact the services you choose; no personal data is uploaded to the developer. See the English privacy policy.

Backups may contain contact names/numbers, full URLs and photo thumbnails. Imports add copies after confirmation; system actions need reconfiguration. Support: lvyufeng@cqu.edu.cn or GitHub Issues.
